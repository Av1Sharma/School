# School

Coursework and programming projects collected in one repository. Each directory contains independent assignments; see its README and course instructions for setup.

| [ITProgDE](ITProgDE/) | ITP150 Python projects |

## Working here

Clone this repository, then open the directory for the assignment you want to work on. Dependencies and entry points vary by project. Commit future changes to this repository from the `School` root.

## Original repositories

The original GitHub repositories remain separate to preserve their commit histories. This repository starts with a snapshot of their files; earlier commits remain in the original repositories.

Existing project README files may refer to their original repository URLs. Any licenses and attribution within each project continue to apply.
